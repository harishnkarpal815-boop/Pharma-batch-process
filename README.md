# Pharma Batch Process

## Introduction

This project explains the batch process used in the pharmaceutical industry.

## Objectives

- Understand the concept of batch manufacturing
- Understand the major steps involved in a pharmaceutical batch process
- Learn about quality control and GMP requirements

## Batch Process Flow

Dispensing → Mixing → Granulation → Drying → Compression → Coating → Packing
